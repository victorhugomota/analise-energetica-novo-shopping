# Análise Energética — Retrofit Novo Shopping

Portal web interativo de engenharia para estudo de viabilidade técnica, econômica e socioambiental do retrofit térmico dos sistemas de climatização por CLPs.

🌐 **Acesse o Painel Online:** [https://victorhugomota.github.io/analise-energetica-novo-shopping/](https://victorhugomota.github.io/analise-energetica-novo-shopping/)

## Funcionalidades
- **Dashboard Financeiro:** Indicadores de CAPEX, OPEX, Payback, ROI, VPL e Redução de Carbono (ESG).
- **Dados dos Equipamentos:** Cadastro e Perfil de Uso de 38 climatizadores com edição em tempo real.
- **Parâmetros Gerais:** Configuração dinâmica de tarifas, setpoints e duty cycles.
- **Relatório para Impressão:** Layout executivo pronto para impressão e exportação em PDF.
- **Persistência em Nuvem:** Integração direta com Firebase Firestore.
